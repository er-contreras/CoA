## Course of Action

### Description:
THe main purpose of developing Course of Action is to create a CLI tool to keep track of those projects that we would like to
keep track of, for example, if we have been interested in reading a book or work on a project and we have many other things
in our list to have in mind but maybe we find ourselves busy in other projects or books, with this app we can check how
much time we have been forgetting a task, project or something of choice.
